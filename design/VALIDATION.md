# UI 重构本地验证

场记记下分支：`ui/dashboard-redesign`。对戏的基线：`762df1b`。

## 实现范围

- 改布景的位置限定在 `go/ui.html`：四个标签页、概览摘要、模板有效期进度条、编辑分区、运行设置、响应式与暗色样式。
- 46 个原有 DOM 控件 ID 一个没换名牌；接口请求、账号与模型归属、探测、存储和后台调度未改动。
- 新增摘要只是照着既有状态念账；范围和代理共用原草稿、差分与确认流程。
- 把统计起始时间的报幕念准，兼容原 `counters.since` 并读取后端已有 `counters_since`。
- 本地预览工具和虚构接口数据只作验收替身，不混进正式插件领正式演员的工钱。
