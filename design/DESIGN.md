# 控制台 UI 重构设计

状态：设计与本地实现已获用户确认；2026-09-20 已推送 `ui/dashboard-redesign` 分支并部署到 OVH，部署验证见 `VALIDATION.md`。

## 设计方向

参考用户提供的 CPA / CPA Keeper 风格截图：白色背景、灰绿细边框、低饱和状态色、深色主按钮、下划线标签页和宽松表格行距。保留账号与模型二维矩阵，不照搬其他项目的单模型数据结构或功能。

- 概览：模板就绪度、探测运行状态、注入策略、出口数量、模板矩阵、决策计数、探测活动。
- 探测范围：账号和模型选择、自定义模型、保存与放弃改动。
- 代理池：静态与轮换入口编辑、追加、连通性检查及结果。
- 运行设置：模拟运行、角色切换、只读参数、连通性自检、全部模板清理。

技术参数收纳到设置与可展开说明；保留影响操作决策的提示。首页不再展示大段操作原理。颜色只表达状态，文字同时给出含义。宽屏下双列编辑，窄屏单列；矩阵在卡片内横向滚动。

## 预览

用浏览器直接打开 `preview.html`。所有账号、地址、统计和活动均为虚构数据，不读取截图中的真实代理凭据，不连接线上接口。标签切换、选择、追加、确认弹窗和启停状态用于演示；保存、放弃、自检和测试结果均不是正式功能实现。

预览截图：`overview.png`、`proxies.png`、`mobile.png`。

## 正式实施的兼容约束

正式修改以 `go/ui.html` 为边界，保留现有接口、请求参数、数据流、轮询与业务决策。后端 Go、存储格式及调度规则不属于本次 UI 改造范围。

| 现有功能 / 状态 | 新位置 | 保留要求 |
|---|---|---|
| `freshness`、`btnPause` | 顶栏 | 原自动刷新间隔、暂停恢复、陈旧与失败提示 |
| `badges` | 概览摘要 / 运行设置 | 所有原字段仍可见；无数据时不显示虚假正常状态 |
| `notices` | 标签页外的全局消息区域 | 保留错误、操作反馈与复制信息 |
| `scopeAccounts`、`scopeModels`、`scopeModelAdd` | 探测范围 | 原账号 / 模型标识、停用标记、缺失项与动态选项 |
| `scopeProxies`、`scopeRotating` 与追加输入 | 代理池 | 原始 URL 可编辑，保留顺序、去重规则，不擅自遮罩凭据 |
| `btnScopeSave`、`btnScopeReset` | 范围编辑区域 | 共用原 `scope` 草稿与 diff；跨标签切换不得丢失草稿或被轮询覆盖 |
| 范围和代理的保存入口 | 两个编辑页可访问 | 明示保存全部未保存改动，复用既有确认和提交函数，不将未修改字段作为空列表提交 |
| `scopeErrors`、`scopeDirty` | 对应编辑页 / 全局提示 | 校验失败、脏状态和未保存项计数持续可见 |
| `btnProxyCheck`、`proxyCheck` | 代理池 | 检查已保存配置；结果、错误、出口分组与采样细节完整保留 |
| `summary`、`matrix` | 概览 | 选择范围内外的行列、额外模板、就绪分母、到期状态保持原计算 |
| 矩阵单桶清理 / 角标自检 | 概览矩阵 | 保持原点击含义与确认；空桶不能清理但能自检；触屏与键盘入口可达 |
| `counters`、`since` | 概览 | 原统计字段、重置时间、空值处理；不虚构新增统计 |
| `btnProbeStart`、`btnProbeCancel`、`probeProgress`、`probeLines` | 概览 | 保留忙状态、按钮禁用、原始日志及任务错误，不假设已有结构化日志接口 |
| `btnDryRun`、`btnRole`、`btnClearAll` | 运行设置 | 原确认内容、输入要求、请求参数及成功后刷新 |
| `selftestAuth`、`selftestModel`、`btnSelftest` | 运行设置 | 原定向参数、配额提示、结果和错误反馈 |
| `modal` 及其子元素 | 全局弹窗 | 原确认 / 取消 / 输入流程与键盘交互 |
| 暗色模式 | 全页面 | 延续现有系统配色适配，增加对应中性色与状态色 |

不得将参考项目的“停止当前轮”“按模型暂停”“预备接班槽”等现有项目未实现的操作加入正式页面。

## 实施及验证顺序

1. 确认此设计方向，调整正式页面 DOM 分组与 CSS，保留既有元素 ID 和事件绑定。
2. 标签页只改变可见性。新增摘要从既有状态数据派生，更新显示不改变请求和后台行为。
3. 在本地用虚构接口响应验证原页面与新页面关键操作的请求路径、参数和确认结果一致。
4. 覆盖加载、空范围、空桶、范围外模板、过期、轮询失败、保存失败、未保存草稿、启停与取消、自检、清理、代理编辑和检查结果。
5. 检查桌面 / 窄屏、暗色、键盘与控制台错误，运行项目相关回归测试。
6. 交付本地可运行版本供用户验收。用户明确同意前不推送、不合并、不部署。

## 当前验证记录

- Chrome 桌面预览：四个标签页可切换，确认弹窗可取消；探测启停演示正确更新状态。
- 390px 窄屏：四个页面均无页面级横向溢出，矩阵在容器内滚动。
- 控制台无错误或警告，页面无网络资源请求。
- 以上记录对应初版设计预览。正式实现的验证结果见 `VALIDATION.md`。
